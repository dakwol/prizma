---
title: RFC
description: Предложения по изменениям платформы «Призма».
---

RFC используется для предложений, которые требуют обсуждения до принятия решения.

После обсуждения RFC может привести к ADR, изменению архитектурной книги, продуктовому
решению или отказу от предложения.

Новые предложения создаются из [шаблона RFC](./template/).
