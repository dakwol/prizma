---
title: Архитектурная книга
description: Основной источник архитектурного описания платформы «Призма».
---

Архитектурная книга фиксирует модель мышления, границы и инженерные решения платформы
«Призма».

Книга развивается по мере принятия решений командой. Текущая версия содержит базовый
фундамент и черновики разделов, которые предстоит раскрыть отдельно.
