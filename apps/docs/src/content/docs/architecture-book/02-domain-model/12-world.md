# Мир

## Статус

Accepted

---

## Введение

Все ранее определённые сущности существуют не самостоятельно.

Они существуют внутри единой модели.

Эта модель называется миром.

Мир является центральным понятием архитектуры платформы.

---

## Что такое мир

Мир представляет собой полную цифровую модель некоторой области существования.

Он объединяет:

- объекты;
- компоненты;
- отношения;
- события;
- пространство;
- время;
- сценарии.

Никакой элемент модели не существует вне мира.

---

## Мир не является приложением

Приложение работает с миром.

Интерфейс отображает мир.

Интеграции изменяют мир.

Но ни приложение, ни интерфейс, ни база данных не являются самим миром.

Они представляют лишь различные способы взаимодействия с одной моделью.

---

## Целостность

Все элементы мира образуют единую непротиворечивую систему.

Изменение одной части мира может повлиять на остальные только через архитектурные механизмы платформы.

---

## Независимость

Мир существует независимо от способа его представления.

Он может отображаться:

- в виде карты;
- в виде таблицы;
- в виде графа;
- в виде трёхмерной сцены;
- в любом другом представлении.

Представление не изменяет модель мира.

---

## Границы

Мир определяет верхнюю границу доменной модели.

Все остальные архитектурные сущности существуют только внутри него.

---

## Заключение

Мир является не совокупностью данных.

Он является целостной цифровой моделью существующей реальности.

Именно мир представляет собой главный объект моделирования платформы «Призма».
