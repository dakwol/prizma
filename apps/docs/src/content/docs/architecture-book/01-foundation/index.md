Раздел фиксирует исходную рамку платформы «Призма»: назначение, продуктовый замысел,
границы ядра и архитектурные принципы.

## Статус

Draft. Тезисы первого раздела считаются рабочей основой для дальнейшей детализации, но
могут уточняться через ADR и RFC.
