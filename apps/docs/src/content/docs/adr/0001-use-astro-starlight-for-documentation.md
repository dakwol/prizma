# ADR-0001: Использовать Astro + Starlight для документации

## Статус

Accepted

## Дата

2026-07-25

## Контекст

Платформе «Призма» нужен публикуемый сайт архитектурной документации на русском языке с
поддержкой Markdown, MDX, поиска, светлой и тёмной темы, подсветки кода и удобной
структуры разделов.

Документация должна жить рядом с исходным кодом и проверяться в CI.

## Рассматриваемые варианты

- Astro + Starlight.
- Собственная документационная оболочка на Astro.
- Универсальный static site generator без специализированной темы документации.

## Решение

Использовать Astro + Starlight для сайта документации.

## Последствия

Starlight даёт готовую структуру документационного сайта, поиск, навигацию,
локализацию и темы без разработки собственной оболочки.

Репозиторий получает отдельное приложение `apps/docs`, которое можно собирать и
публиковать независимо от будущих backend и frontend частей платформы.

Архитектурная книга хранится в стандартной content collection Starlight:
`apps/docs/src/content/docs`.
