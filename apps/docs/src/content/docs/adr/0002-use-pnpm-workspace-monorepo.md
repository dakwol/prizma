# ADR-0002: Использовать pnpm workspace monorepo

## Статус

Accepted

## Дата

2026-07-25

## Контекст

Репозиторий «Призма» должен стать фундаментом платформы и со временем вместить
документацию, общие пакеты, инструменты, frontend и backend-границы.

На текущем этапе нужно создать лёгкий monorepo без генерации backend-проектов и
демонстрационных приложений.

## Рассматриваемые варианты

- pnpm workspaces.
- npm workspaces.
- Yarn workspaces.
- Несколько отдельных репозиториев.

## Решение

Использовать pnpm workspaces.

## Последствия

pnpm workspaces позволяют явно описать рабочие области `apps/*`, `packages/*` и
`tools/*`, держать единый lockfile и запускать команды через фильтры.

Корневой пакет остаётся приватным, чтобы не публиковать monorepo как npm-пакет.
