# Contributing

Репозиторий находится на ранней стадии архитектурного проектирования.

## Общие правила

- Не добавляйте backend, frontend, базы данных, Docker-инфраструктуру или API без
  принятого решения команды.
- Фиксируйте существенные архитектурные решения через ADR.
- Используйте RFC для предложений, требующих обсуждения.
- Поддерживайте `pnpm quality` в рабочем состоянии.
- Не добавляйте неподтверждённые продуктовые обещания, сроки или доменные правила.

## Документация

Основная архитектурная документация находится в `apps/docs/src/content/docs`.

Корневой каталог `docs/` зарезервирован для будущей внутренней инженерной документации и
не является источником публикуемой архитектурной книги.
